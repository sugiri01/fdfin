Course Curriculum

Module 1: Foundations of Financial Modeling

Topic Description
Excel for Financial Modeling Formulas, functions, formatting, data validation, and pivot tables.
Time Value of Money NPV, IRR, annuities, compounding – manual + Excel-based.
Financial Statements Overview Balance Sheet, Income Statement, and Cash Flow basics.
Ratio Analysis Liquidity, profitability, solvency, and efficiency ratios.

Module 2: Building a Financial Model

Topic Description
Revenue Projections Forecasting using historical data + linear regression.
Cost Modeling Fixed vs. variable cost breakdown and driver assumptions.
Capital Expenditure & Depreciation Depreciation models, CAPEX schedules.
Working Capital & Tax Modeling Inventory, payables, receivables, tax forecasts.
Integrated 3-Statement Model Linking Income, Balance Sheet, and Cash Flow.

Module 3: Introduction to AI in Finance

Topic Description
Basics of AI/ML Supervised vs. unsupervised learning, key algorithms.
Python for Finance Pandas, NumPy, matplotlib, scikit-learn – quickstart.
AI Tools & Frameworks Overview of ChatGPT, Google Sheets AI, Excel Copilot, etc.

Module 4: Predictive Modeling in Finance

Topic Description
Forecasting Revenues with ML Time-series, regression, ARIMA, Prophet.
Credit Risk Modeling Logistic regression, decision trees on credit score data.
Stock Price Prediction (Optional) Using LSTM/ML models to forecast stock trends.
Clustering for Customer Segments K-means clustering for identifying buyer personas.

Module 5: Generative AI for Financial Tasks

Topic Description
Prompt Engineering for Finance Using ChatGPT for valuation, financial writing.
Automating Reports Generating dashboards, monthly financial summaries.
AI-Powered Scenario Analysis ChatGPT + Excel/Notion integrations for risk simulations.
NLP for Financial Documents Parsing annual reports, extracting KPIs with LLMs.

Module 6: Capstone Project

Project Ideas Description
Build a Startup Financial Model End-to-end model for a SaaS/retail startup.
Forecast Sales for a Company using AI Integrate Prophet/ChatGPT for forecasting.
Automate Financial Reporting Build a script with OpenAI to create monthly reports.
